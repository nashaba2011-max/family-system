# برنامج عائلة النشابة

نسخة ويب من برنامج Access لسجل العائلة: إضافة وتعديل وحذف الأفراد برقم التسلسل، الملف الكامل (6 تبويبات)، النسب والزوجات، الشجرة، 27 تقريراً قابلاً للطباعة والتصدير، القوائم والمناطق، المستخدمون بصلاحيات (إضافة/تعديل/حذف)، الاستيراد والتصدير من Excel، ومراسلة واتساب.

- الواجهة: HTML + JavaScript بدون بناء — تُنشر مباشرة على GitHub Pages.
- البيانات: Supabase (جداول `fa_people`, `fa_spouses`, `fa_lookups`, `fa_users`) محمية بسياسات RLS.
- الإعدادات في `js/config.js`.

## إضافة مستخدم
1. المدير يضيف البريد من شاشة «المستخدمون» ويحدد صلاحياته.
2. المستخدم يفتح الرابط، يكتب بريده وكلمة سر جديدة، ويضغط «أول مرة؟ أنشئ كلمة سر».
